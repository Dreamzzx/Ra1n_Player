# Rain_Player

#### 介绍

一款用ffmpeg从底层开发的播放器，Qt播放，具有三层包装，UI与内核沟通之间设计了消息队列。支持的功能包括：音视频播放、停止、暂停、逐帧、拖动、SEEK查找、变速播放、硬件解码。
